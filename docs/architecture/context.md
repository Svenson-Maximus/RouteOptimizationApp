# C4 - System Context

## Purpose
Describe external actors and systems interacting with the platform.

## Primary Actors
- Bakery Staff (operations, data correction)
- Planner/Dispatcher (runs and inspects optimization)

## External Systems
- Google Maps APIs (geocoding/place resolution)
- AWS Platform Services (hosting, storage, database)

## System Boundary
The platform includes UI, business services, and optimization engine.
Outside boundary: users and third-party APIs.
